# C语言基础学习

## 1. 学习目标

建立扎实的 C 语言基础，为后续嵌入式软件开发、MCU 驱动开发、RTOS 应用以及系统级工程能力建设打基础。

学习目标不是停留在语法记忆，而是理解 C 语言在计算机系统中的运行机制，并能够：

- 阅读复杂嵌入式 C 代码
- 独立设计模块化 C 程序
- 分析内存、编译、链接相关问题
- 使用工程化方式开发 C 项目
- 为后续 STM32、FreeRTOS、Linux Embedded 学习建立基础


---

- 函数
- 作用域

# 3. 学习方式

采用工程化学习流程：

```text
理论学习

↓

代码实验

↓

编译运行

↓

Debug分析

↓

总结记录

↓

Git提交
```



每一个重要知识点形成：

- 学习笔记
- 示例代码
- 实验记录
- 问题总结
