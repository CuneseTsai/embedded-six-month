# C Language Foundation

> 面向嵌入式软件开发的 C 语言基础能力建设。


## 一、学习目标

C语言是嵌入式软件开发的核心基础。

本阶段目标不是简单掌握语法，而是建立：

- C语言运行机制理解
- 内存模型理解
- 指针与数据结构能力
- 编译链接基础认知
- 工程化代码组织能力
- 面向嵌入式开发的 C 编程习惯


最终目标：

能够阅读、设计和维护中大型嵌入式 C 工程代码。

# 四、学习方式

每个知识点尽量形成完整闭环：

```text
理论学习

↓

代码实现

↓

运行验证

↓

问题记录

↓

Git提交

↓

学习总结
```

避免：

- 只看视频
- 只背语法
- 只复制代码

重点培养：

```text
理解 → 实现 → 调试 → 总结
```
