## 4. 当前学习任务

### C 语言：内存布局与编译器行为

**当前状态：进行中，尚未完成掌握验证。**

关联文件：

- `learning/00_c_language/exercises/01_memory_layout/memory_layout.c`
- `learning/00_c_language/exercises/01_memory_layout/memory_layout.o`
- `learning/00_c_language/exercises/01_memory_layout/memory_layout_O0.s`
- `learning/00_c_language/exercises/01_memory_layout/memory_layout_O2.s`

已观察到的实验现象：

- 已生成并查看 `-O0` 与 `-O2` 编译结果。
- 在 `-O0` 汇编中观察到栈帧及局部变量相关的栈偏移，例如 `-4(%rbp)`、`-8(%rbp)`、`-12(%rbp)`。
- 在 `-O2` 汇编中观察到编译器将部分计算结果直接用于输出，例如将结果 `70` 作为 `printf` 的参数，体现了优化可能消除中间变量或预先计算表达式。

以上记录表示已观察到相应现象，不代表已经完整理解所有汇编指令、ABI 规则或编译器优化机制。
