# 项目文档导航

本文档用于快速定位嵌入式工程师成长计划中的路线规划、学习状态、学习记录和工程资料。

## 1. 当前学习状态

- [学习状态总表](learning-status.md)：当前学习任务、已验证进度、知识缺口和下一步起点。
- [学习日志规范](learning-log/README.md)：学习日志的命名、结构和记录原则。

## 2. 路线规划

- [六个月学习路线](roadmap/six-month-roadmap.md)：阶段目标、能力要求和总体执行计划。
- [项目目录与规划](roadmap/project-catalog.md)：1 + 4 + N 项目体系及各项目定位。
- [芯片平台路线](roadmap/platform-roadmap.md)：不同芯片平台的学习优先级与长期规划。
- [源码学习路线](roadmap/source-study-roadmap.md)：源码学习的规划与方法。

## 3. 学习记录与复盘

- [学习日志目录](learning-log/README.md)：学习日志的统一规范。
- [每周复盘目录](weekly-review/README.md)：阶段复盘与问题总结。

## 4. 工程资料

- `engineering/`：工程实践、开发规范与项目过程资料。
- `knowledge/`：经过整理的技术知识与专题资料。

## 5. 文档维护原则

1. 路线规划记录目标和计划。
2. 学习日志记录每次实际学习、实验和调试过程。
3. 学习状态总表记录当前进度、已验证能力、知识缺口和明确的续学起点。
4. 每次学习结束后，根据实际证据更新学习日志和学习状态总表。
5. 计划中的内容不能直接标记为已完成；完成操作不等于掌握知识。
6. 调整长期目标或阶段计划时，再更新对应的路线规划文档。
